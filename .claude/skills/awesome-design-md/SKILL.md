# Awesome DESIGN.md

Each `design-md/<brand>/DESIGN.md` describes that brand's design tokens, typography, components and rules. To use one: list `design-md/`, read the matching `DESIGN.md`, and follow it when generating UI. Source: https://github.com/VoltAgent/awesome-design-md
