# Pinterest free pins: bulk upload (drafted 2026-10-12, nothing posted)

File: `reports/pinterest-bulk-pins-2026-10-12.csv` (20 pins, 2 a day from 2026-10-13 to 2026-10-22).

1. In Pinterest, create 3 boards with these exact names: "Bathroom Decor Ideas", "Rugs, Mats & Cosy Corners", "Wall Art & Seasonal Decor".
2. Pinterest (web, on a computer) -> Create -> Create Pin -> Create in bulk (or Business hub -> Create -> Bulk create pins) -> upload the CSV.
3. Check the preview: every row should show the image, board and date. Fix any row Pinterest flags.
4. Submit. Pins post on the scheduled dates.

Copy uses only facts from the product pages. No ratings, no health claims, no brand names. Links carry utm_source=pinterest&utm_medium=organic_pin&utm_campaign=oct26_free_pins so Shopify shows Pinterest as the source.
